# software-seguro

Repositorio de documentación técnica del curso de Ciberseguridad. Cada módulo del curso tiene su propia carpeta, y dentro de cada módulo hay un subdirectorio por objetivo, con los `.md` de desarrollo/documentación y los `.pdf` de reportes técnicos cuando corresponda.

## Estructura

```
software-seguro/
└── Modulo_I/
    ├── Objetivo_1_Mapeo_Logico/
    │   └── objetivo_1_mapeo_logico.md
    ├── Objetivo_2_Laboratorios/
    │   └── objetivo_2_laboratorios.pdf   (reporte final del laboratorio)
    ├── Objetivo_3_Handshake_TLS/
    │   └── objetivo_3_handshake_tls.md
    └── Objetivo_4_Instalacion_Proxy/
        └── objetivo_4_instalacion_proxy.md
```

## Convención para nuevos módulos

Al sumar `Modulo_II`, `Modulo_III`, etc., replicar la misma lógica: una carpeta `Modulo_N/` con un subdirectorio `Objetivo_X_<nombre_corto>/` por cada objetivo del módulo.
